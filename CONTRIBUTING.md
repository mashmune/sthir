# Contributing

1. Fork, create a branch, make a change.
2. Run `python3 -m unittest`. Every change needs a test. All tests must pass.
3. Open a pull request that says what changed and why.

Rules of thumb: no new dependencies without a strong reason (the project must install on a phone with `pkg install python python-cryptography`),
no secrets in commits, and no claims in docs that the code does not back up.
